# AutoFolderColors

I made this addon because I often had to colorize my folders for ease of navigation. And when transferring folders to another project, the color scheme was reset.

Project → Tools  → Apply Auto Folder Colors

You can change the color scheme by adding or removing keys from the `COLORS_RULES` dictionary to `auto_folder_colors.gd `.

In future versions, I will add a resource where you can customize the color scheme (the resource itself has already been created, who does not want to wait, you can change the add-on code so that it works with this resource.)
